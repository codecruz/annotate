Point at your page, write the change, let Claude do it

annotate is a Claude Code plugin. It puts an annotation layer over the site you are running locally: click an element, leave a note, and Claude finds the code behind it and makes the change.

Install it Read the docs
Try it: click any part of this sample page and leave a note.

    
This is what Claude reads: .annotations.json in your project.

  

  
What a note carries: the page, the element and its text, the window size and the colour theme. “Too big on mobile” arrives with its context.


  

    
Why annotate

    

      

        
Show, don’t describe

        
No more “the second card under the header”. Click the thing and say what you want.

      

      

        
Works with what you run

        
Any site already served on localhost: a static build, Astro, Next.js, Django, anything. Only Node 18 is needed, and your project is not modified.

      

      

        
Pins are your to-do list

        
Claude removes each note it resolves. The pins left on the page are the work still open.

      

      

        
Notes across pages

        
Annotate the whole site in one pass. The notes list takes you back to each one.

      

      

        
Mouse, touch or keyboard

        
Pick elements with the arrow keys and Enter, widen a pick to its container, and read every note with a screen reader.

      

      

        
English and Spanish

        
The layer follows your browser language. Write the notes in any language you like.

      

    

  


  

    
Get started

    
    
      
  1. 
        
    Install the plugin. In Claude Code:
    
        
    /plugin marketplace add codecruz/claude-plugins
/plugin install annotate@codecruz
    
        
    Then start a new session, or run /reload-plugins.
    
      
    2. 
      
  2. 
        
    Serve your project locally as you always do, and ask Claude:
    
        
    I want to annotate the site
    
      
    3. 
      
  3. 
        
    Open the address Claude gives you. Press Annotate, click an element, write the note and save. Repeat on any page.
    
      
    4. 
      
  4. 
        
    Tell Claude you are done. It makes each change and reports note by note.
    
        
    Done, apply my notes
    
      
    5. 
    

  


  

    
Privacy

    
    
      
  • Everything stays on your computer. The notes live in .annotations.json, inside your project.
    • 
      
  • The helper only listens on 127.0.0.1 and only forwards to localhost. It cannot be pointed at a public site.
    • 
      
  • Your project files are not changed by the layer: it is added to the pages on the fly, only while the session is open.
    • 
      
  • No accounts, no network calls, no analytics.
